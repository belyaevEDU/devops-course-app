# Модуль Requester
Модуль отвечает за отправку запросов в API ЦБ РФ и парсинг ответа API для последующей отправки данных модулем [**server**](/server/README.md).
## Имплементация
Модуль разделен на 4 файла:
1) `__init__.py` - содержит конечные функции, которые далее использует [**server**](/server/README.md).
2) `parser.py` - содержит функции, которые парсят ответы API и выдают нужные данные
3) `cached_session.py` - содержит функции, которые создают и управляют объектом `CachedSession`, который может кэшировать HTTP-запросы, храня данные в кэше ближайший день. Используется для избежания повторных запросов данных о курсе валют на сегодняшний день.
4) `utils.py` - содержит общие helper-функции, документация для каждой описана внутри `.py` файла.
### Как работает модуль
#### `__init__.py`: getBankApiResponse
Серверу нужна только функция `getBankApiResponse`, которая принимает строковые `currency` и `date` *(те же самые query-параметры)* и выводит тип `dict[str, float]`: словарь, где ключи - uppercase названия валют, а значения - их курс к рублю. **Функция ожидает уже валидные query-параметры согласно описанным [в общем README](/README.md) стандартам и форматам.** Как работает функция:

Если дата не передается, то вызывается get объекту класса `DailyCachedSession`, передавая ему *по сути* базовый URL. Если дата передается, то мы собираем URL для запроса согласно стандарту API ЦБ РФ и вызываем get библиотеке `requests`, которая без какого-либо кэширования бьет запрос в открытый интернет. В обеих случаях, мы получили ответ: данные из API согласно запросу.

Далее, если response код не равен 200, мы вызываем `HTTPError` по коду.

Далее, мы вызываем функции из `parser` согласно тому, передавался ли нам query-параметр `currency`:
- если да, то вызываем функцию `getSelectCurrencyRate`, которая принимает на вход строковые `response` и `userCurrency`, возвращает `dict[str, float]`, который будет содержать единственную key-value пару: uppercase название требуемой валюты и её курс к рублю;
- если нет, то вызываем функцию `getAllCurrencyRates`, которая принимает на вход строковый `response`, возвращает `dict[str, float]`, который будет содержать key-value пары: uppercase названия всех валют и их курсы к рублю.

**Также, `.py` файлы содержат docstring для функций, требующих документации.**
