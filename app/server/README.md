# Модуль server
Модуль отвечает за запуск FastAPI сервера, который будет отвечать на запросы согласно схеме, описанной в [README приложения](/app/README.md)
## Имплементация
Модуль разделен на 3 файла:
1) `__init__.py` - содержит функцию, которая запускает сервер
2) `app.py` - описывает логику сервера
3) `query_validation.py` - содержит функции, которые используются для валидации query-параметров согласно стандартам и форматам, описанным в [README приложения](/app/README.md)
### Как работает модуль
Функцией `server.run()` запускается сервер, описанный в `app.py`. Порт сервера берется из переменной окружения PORT (default=8000).

К тому же, приложение инструментируется для Prometheus с помощью модуля [prometheus-fastapi-instrumentator](https://pypi.org/project/prometheus-fastapi-instrumentator/), который на отдельном HTTP сервере с портом, который берется из переменной окружения PROMETHEUS_PORT (default=9100), отдает метрики на ручке `/metrics`.

Логика запросов описана в [README приложения](/app/README.md).

Данные о версии и авторе для запроса `GET /info` берутся из переменных окружения: VERSION (default=1.0.0), AUTHOR (default=v.belyaev).
