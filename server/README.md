# Модуль server
Модуль отвечает за запуск FastApi сервера, который будет отвечать на запросы согласно схеме, описанной в [общем README](/README.md)
## Имплементация
Модуль разделен на 3 файла:
1) `__init__.py` - содержит функцию, которая запускает сервер
2) `app.py` - описывает логику сервера
3) `query_validation.py` - содержит функции, которые используются для валидации query-параметров согласно стандартам и форматам, описанным в [общем README](/README.md)
### Как работает модуль
Функцией `server.run()` запускается сервер, описанный в `app.py`. Порт сервера берется из переменной окружения PORT (default=8000).

Логика запросов описана в [общем README](/README.md).

Данные о версии и авторе для запроса `GET /info` берутся из переменных окружения: VERSION (default=1.0.0), AUTHOR (default=v.belyaev).

`app.py` написана достаточно декларативно. Документация для функций в `query_validation.py` описана внутри `.py` файла.
